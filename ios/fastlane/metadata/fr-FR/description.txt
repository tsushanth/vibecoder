VibeBuild is a curated catalog of web app examples for learning HTML, CSS, and JavaScript by reading real code.

Browse 30 hand-picked projects across difficulty levels — Beginner, Intermediate, Advanced — and categories like layouts, games, mobile UIs, productivity, and creative tools. For each project you can:

• Read the full source code, file by file
• Tweak the code in-app to see how it works
• Run the preview in a strictly sandboxed WebView (no network access)
• Visit the project's GitHub repo (when available)

WHAT'S INSIDE
• SaaS Landing Page — hero, features, pricing, FAQ
• Drawing App — HTML5 canvas, brushes, color picker
• Social Media Feed — card layouts, stories bar
• Kanban Task Manager — drag and drop, local storage
• Markdown Notes — real-time markdown rendering
• Pixel Art Editor — pixel grid, color palette
• Plus 24 more projects covering games, dashboards, generators, and UI patterns.

HOW THE SANDBOX WORKS
Every preview runs inside an isolated WebView with a strict Content Security Policy. The preview cannot reach the network, call native iOS code, or navigate to external URLs. This is why VibeBuild works completely offline.

WHO IT'S FOR
• Beginners who want to learn by reading real code, not toy snippets
• Intermediate devs looking for layout, animation, and UI patterns
• Anyone curious about how a particular UI is built
